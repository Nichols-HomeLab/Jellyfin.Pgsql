PostgreSQL Database Configuration

This plugin uses environment variables for configuration. Prefer a single Npgsql connection string, or use the legacy individual variables.

Preferred Environment Variable

  • POSTGRES_CONNECTION_STRING - Complete Npgsql connection string
  • JELLYFIN_POSTGRES_CONNECTION_STRING - Alias for the same setting

Legacy Environment Variables

  • POSTGRES_HOST - Database host (default: localhost)
  • POSTGRES_PORT - Database port (default: 5432)
  • POSTGRES_DB - Database name (default: jellyfin)
  • POSTGRES_USER - Database user (default: jellyfin)
  • POSTGRES_PASSWORD - Database password (required in legacy mode)

Example Docker Compose

environment:
  - POSTGRES_CONNECTION_STRING=Host=postgres;Port=5432;Database=jellyfin;Username=jellyfin;Password=your_secure_password
